# Blief System Comparison

A framework for evaluating belief systems based on law, institutions, and lived outcomes rather than theoretical claims.

## Key Features
*   **Outcomes over Dogma**: Scores based on real-world impact.
*   **11-Point Rubric**: Weighted metrics covering human rights, governance, and freedom.
*   **Weighted Scoring**: Penalties for uncertainty and severe active harms.

Goal: To provide an objective, evidence-based comparison of belief systems.
