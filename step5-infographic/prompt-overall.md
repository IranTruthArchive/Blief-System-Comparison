# Infographic Prompt — Overall Score

Create a clean, professional infographic table displaying the **overall evaluation scores** of belief systems.

## Data

Use the final net-impact scores from the evaluation. Each system should have a score from 0 to 10.

## Layout

- **Title**: "Belief Systems — Overall Evidence-Based Scorecard"
- **Table columns**: Rank | Logo/Symbol | Belief System Name | Score (0–10) | Status Bar
- **Status bar**: A horizontal mini-bar filled proportionally to the score
- **Color coding by score range**:
  - 8–10: Green (#2ECC71) — Strong evidence of net positive impact
  - 5–7.9: Amber (#F39C12) — Mixed evidence, significant concerns remain
  - 2–4.9: Red-Orange (#E74C3C) — Strong evidence of net harm
  - 0–1.9: Dark Red (#922B21) — Severe, systematic harm documented
- **Row background**: Alternate subtle gray (#F8F9FA) and white for readability
- **Sort order**: Highest score to lowest

## Design Rules

- White background, no decorative elements, no borders on outer edges
- Font: Clean sans-serif (Inter, Helvetica, or similar)
- Logo/symbol column: small monochrome icon or symbol representing each system
- Score number displayed in **bold**, colored to match its status range
- Minimal footnote at bottom: *"Scores derived from documented evidence across 11 evaluation dimensions. See full report for methodology and sources."*
- Aspect ratio: Vertical, optimized for sharing on social media and messaging apps
