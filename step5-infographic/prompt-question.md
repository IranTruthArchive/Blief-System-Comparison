# Infographic Prompt — Single Question Scorecard

Create a clean, professional infographic table displaying the scores of 19 belief systems for **{{Q_NUMBER}}: {{Q_TITLE}}**.

## Data

Use the scores from the evaluation for this specific question. Each system should have a score from 0 to 10.

## Layout

- **Title**: "{{Q_TITLE}}" — large, top of infographic
- **Subtitle**: "Q{{Q_NUMBER}} of 11 — Evidence-Based Assessment"
- **Logo**: A small monochrome icon or symbol representing the question category
- **Table columns**: Rank | Logo/Symbol | Belief System Name | Score (0–10) | Status Indicator
- **Status indicator**: A colored circle (dot) next to the score
- **Color coding by score range**:
  - 8–10: Green (#2ECC71) — Strong positive record
  - 5–7.9: Amber (#F39C12) — Mixed record, concerns documented
  - 2–4.9: Red-Orange (#E74C3C) — Significant harm documented
  - 0–1.9: Dark Red (#922B21) — Severe harm documented
- **Row background**: Alternate subtle gray (#F8F9FA) and white for readability
- **Sort order**: Highest score to lowest

## Design Rules

- White background, no decorative elements, no outer borders
- Font: Clean sans-serif (Inter, Helvetica, or similar)
- Logo/symbol column: small monochrome icon or symbol representing each system
- Score number displayed in **bold**, colored to match its status range
- Minimal footnote at bottom: *"Score based on documented evidence — scriptures, legal records, human rights reports, and independent scholarship."*
- Aspect ratio: Vertical, optimized for sharing on social media and messaging apps
